# 물비늘 — 연이승의 어장

Unity 2022.3 LTS와 C#으로 만드는 PC용 3D 스토리 게임입니다. 주인공은 17세 여성 연이승입니다. 연섬의 어장을 관리하면서 또래 임찬우의 마음을 낚으려 하지만, 허세와 유혹으로 얽힌 관계가 섬의 축제와 함께 비극으로 기울어지는 청소년 드라마입니다. 성적인 콘텐츠는 없습니다.

## 프로젝트 열기

Unity Hub에서 `UnityProject/` 폴더를 여세요. 프로젝트 에디터 스크립트가 첫 실행 때 시작 장면을 만들고 Windows 빌드 장면 목록에 추가합니다. Unity가 스크립트를 불러온 다음 Play를 누르면 됩니다.

Windows 실행 파일은 **File → Build Profiles → Windows → Build**에서 생성합니다. Unity Editor가 설치되지 않은 현재 작업 환경에서는 `.exe`를 만들지 못했습니다.

## 게임 설정

- Unity 내장 3D 물리엔진 PhysX 사용
- Rigidbody로 플레이어 이동, 지면 충돌, 점프 처리
- 실제 물 위에 찌를 던지고 부력·흔들림·충돌 반응 적용
- 대화 선택에 호감과 신뢰가 반영되고, 30일째 배드엔딩에 도달
- 진행 상황은 PlayerPrefs에 저장

조작: WASD 이동, 마우스 시점, E 대화/낚시, Space 낚싯대 당기기, Escape 마우스 잠금 해제.

## 현재 범위

현재 저장소는 여성 주인공과 임찬우 첫 루트, 어장 탐험·낚시, 선택 대화, 비극적 배드엔딩을 담는 첫 플레이어블입니다. 5시간 이상 분량의 완성 시나리오와 남성 주인공 루트는 아직 추가 제작이 필요합니다.
