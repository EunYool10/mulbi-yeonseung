# 물비늘 — 연이승의 어장

브라우저에서 실행하는 한국어 3D 스토리 어드벤처 프로토타입입니다. 낚시터 관리 업무를 하며 연이승과 가까워지고, 어장에 숨겨진 기록을 따라갑니다.

## 실행

`index.html`을 최신 브라우저에서 열거나 저장소 루트에서 정적 웹 서버를 실행하세요. Three.js 모듈과 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- WASD: 이동
- 마우스: 시점 회전
- E: 인물 대화 / 장소 상호작용
- 물가: 낚시 미니게임
- ▤: 어장 기록
- ↥: 로컬 저장

진행 상황은 브라우저의 localStorage에 저장됩니다. 메뉴 화면에서 새로고침해도 기록을 이어갈 수 있습니다.

## GitHub Pages

저장소 설정의 **Pages → Deploy from a branch → main → /(root)** 를 선택하면 공개할 수 있습니다. 이 프로젝트는 빌드 과정이 없는 정적 페이지입니다.

## 범위

현재는 분위기, 이동, 첫 만남, 낚시, 기록/저장을 구현한 플레이 가능한 첫 장면입니다. 장편(5시간 이상) 시나리오 전체, 남성 캐릭터 루트, 엔딩 분기와 완성된 콘텐츠는 추가 제작이 필요합니다.
